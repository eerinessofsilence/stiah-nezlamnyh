## Як побудовано гід

Картка маршруту пояснює, з чого почати, куди звернутися, які документи підготувати та що робити в поширених ситуаціях. Пояснення викладено українською своїми словами на основі офіційних матеріалів. Наприкінці картки можна розгорнути «Джерела й перевірка», щоб відкрити першоджерела. Під блоком вказано дату редакції.

У гіді 14 маршрутів, серед них «Після поранення», «Психологічна підтримка», «Сімʼї загиблих» і «Сімʼї безвісти зниклих». Запит «МСЕК» знаходить чинний маршрут оцінювання повсякденного функціонування.

Мобільна збірка містить [знімок каталогу](mobile/src/data/catalog.json), створений з [catalog.js](catalog.js). Пошук і підбір маршрутів працюють на пристрої. Установа, що приймає заяву, розглядає конкретну справу та ухвалює рішення.

## Локальна розробка

З кореня проєкту встановіть залежності та запустіть потрібну платформу. Вимоги до Node.js, Xcode та Android SDK є в [мобільному README](mobile/README.md).

```sh
npm --prefix mobile ci
npm --prefix mobile run check
npm --prefix mobile run ios
# або
npm --prefix mobile run android
```

## Характерник

«Характерник» пояснює терміни на кшталт УБД і ВЛК, показує короткий огляд маршруту й пам’ятає контекст уточнення. На складене запитання він може відповісти кількома розділами та вказати, для якої частини в гіді бракує підтверджених даних. Якщо запит потрібно уточнити, помічник пропонує вибрати тему.

У збірках для App Store та Google Play «Характерник» підбирає відповідь онлайн після явної згоди. Без мережі, без згоди або при збої він шукає у вбудованому каталозі. Dev-збірка також підтримує голосові повідомлення й живу розмову.

### Онлайн-чат у магазинних збірках

Cloudflare Worker обслуговує `POST /api/assistant` на тому самому HTTPS-хості, що й сторінки підтримки та приватності. У профілях EAS `testflight` і `google-play-internal` уже вказано `EXPO_PUBLIC_STORE_ASSISTANT_URL`. Для локальної Release-збірки додайте цю саму змінну в `mobile/.env.local`.

Під час першого розгортання додайте окремий ключ OpenAI як секрет Worker. Усі команди запускаються з кореня проєкту.

```sh
npx wrangler deploy --dry-run
npx wrangler deploy
npx wrangler secret put OPENAI_API_KEY
```

Типові ліміти — 12 запитів за хвилину з однієї IP-адреси в кожній локації Cloudflare та 500 запитань до моделі на добу UTC для всіх користувачів. Одне запитання може виконати до двох викликів API. Точні збіги у гіді обходяться без виклику моделі. Змініть добовий ліміт через `ASSISTANT_DAILY_LIMIT`. Для вимкнення онлайн-режиму задайте `ASSISTANT_ENABLED = "false"` та оновіть Worker. При зміні каталогу нова версія також має потрапити в мобільну збірку. Збірки з іншою версією каталогу продовжать працювати локально.

### Запуск онлайн у Dev

1. Встановіть залежності командами `npm ci` в корені й `npm --prefix mobile ci`.
2. Додайте у кореневий `.env` секрет `OPENAI_API_KEY` сервера. За потреби задайте `PORT` (типово 4173) і `OPENAI_MODEL` (типово `gpt-6-luna`).
3. Запустіть сервер командою `node --env-file=.env server.cjs`. Сервер слухає `127.0.0.1`.
4. Вкажіть у `mobile/.env.local` значення `EXPO_PUBLIC_ASSISTANT_URL=http://127.0.0.1:4173/api/assistant` для iPhone Simulator. Для Android з ADB можна під’єднати той самий порт командою `adb reverse tcp:4173 tcp:4173`. Для тестувальників використовуйте HTTPS-проксі з підтримкою WebSocket, обмеженням доступу та запитів. Задайте `APP_ORIGIN` як HTTPS-origin проксі й `ASSISTANT_DEV_TOKEN` як окремий випадковий код доступу в середовищі сервера. Передайте тестувальникам цей код для екрана «Помічник». Ключ OpenAI потрібен лише серверу.
5. Зберіть Dev-клієнт заново після встановлення нативних залежностей. Для наявного Android-проєкту застосуйте конфігурацію з [мобільного README](mobile/README.md#запуск). Екран «Помічник» підключається автоматично за налаштованою адресою. Для віддаленого сервера введіть виданий код доступу. Мікрофон запитує дозвіл під час першої голосової дії.

У Dev модель за змістом репліки розрізняє коротку розмову й запит до гіда. Для короткої розмови обирає доречну відповідь, а для запитання до гіда бачить увесь його зміст і добирає до чотирьох матеріалів для читання. Сервер додає до двох розділів, знайдених локально. Другим запитом модель складає відповідь з абзаців цих матеріалів і може поєднати кілька тем, запропонувати уточнення або повідомити, що даних бракує. Сервер і застосунок перевіряють номери матеріалів та абзаців. Текст, умови й джерела надходять із тієї самої версії каталогу в застосунку.

Сервер використовує `gpt-transcribe` для записів і `gpt-live-transcribe` для розмови. Озвучення підтримує голос «Микита» через локальний Piper і український системний голос як запасний варіант. За відсутності мережі доступний локальний гід. Питання, аудіо й розшифровки не записуються в журнали застосунку або сервера гіда. Верхня межа в Dev — 60 секунд на запис і 5 хвилин на голосову сесію.

Команда `npm run check` у корені перевіряє текст, запис і WebSocket на тестових відповідях провайдера. Реальні запити до OpenAI потребують ключа.

### Голос «Микита» у Dev

На тому самому комп’ютері, де працює сервер гіда, встановіть [Piper](https://github.com/OHF-Voice/piper1-gpl) в окреме середовище Python і завантажте [голос «Микита»](https://huggingface.co/RomanStasyshyn/uk_UA-mykyta-high). Синтез відбувається на цьому комп’ютері й потребує лише готового тексту відповіді.

```sh
python3 -m venv /tmp/stiah-piper-env
/tmp/stiah-piper-env/bin/python -m pip install 'piper-tts[http]==1.8.0'
mkdir -p /tmp/stiah-piper-voices
/tmp/stiah-piper-env/bin/python -m piper.download_voices --data-dir /tmp/stiah-piper-voices uk_UA-mykyta-high
/tmp/stiah-piper-env/bin/python -m piper.http_server --host 127.0.0.1 --port 5072 --data-dir /tmp/stiah-piper-voices -m uk_UA-mykyta-high
```

В іншому терміналі запустіть `ASSISTANT_PIPER_URL=http://127.0.0.1:5072/synthesize node --env-file=.env server.cjs`. У Dev голос використовується в чаті й у живій розмові. Якщо Piper недоступний, застосунок використовує український системний голос. У магазинних збірках динамік використовує голос пристрою.

### Локальна модель для iPhone Simulator

Запустіть [llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md) із [Qwen3-1.7B GGUF](https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF). Для локальної перевірки ключ OpenAI не потрібен.

```sh
llama-server --model /path/to/Qwen3-1.7B-Q4_K_M.gguf --host 127.0.0.1 --port 4376 --ctx-size 6144 --parallel 1 --jinja --cors-origins localhost --no-webui
PORT=4175 ASSISTANT_LLAMA_URL=http://127.0.0.1:4376/v1/chat/completions node server.cjs
```

Під час запуску збірки для розробки на iPhone Simulator задайте `EXPO_PUBLIC_ASSISTANT_URL=http://127.0.0.1:4175/api/assistant`. Локальну HTTP-адресу використовують для симулятора. На фізичному пристрої потрібна доступна HTTPS-адреса сервера.
