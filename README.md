# Гід: Стяг незламних

Незалежний інформаційний гід для ветеранів і ветеранок війни, людей з інвалідністю внаслідок війни та їхніх родин. Загальноукраїнські порядки доповнюють контакти й можливості Одещини. Гід доступний як [застосунок для iOS та Android](mobile/README.md).

## Як побудовано гід

Картка маршруту пояснює, з чого почати, куди звернутися, які документи підготувати та що робити в поширених ситуаціях. Пояснення викладено українською своїми словами на основі офіційних матеріалів. Наприкінці картки можна розгорнути «Джерела й перевірка», щоб відкрити першоджерела. Під блоком вказано дату редакції.

У гіді 14 маршрутів, серед них «Після поранення», «Психологічна підтримка», «Сімʼї загиблих» і «Сімʼї безвісти зниклих». Запит «МСЕК» знаходить чинний маршрут оцінювання повсякденного функціонування.

Мобільна збірка містить [знімок каталогу](mobile/src/data/catalog.json), створений з [catalog.js](catalog.js). Пошук і підбір маршрутів працюють на пристрої. Установа, що приймає заяву, розглядає конкретну справу та ухвалює рішення.

## Локальна розробка

З кореня проєкту встановіть залежності та запустіть потрібну платформу. Вимоги до Node.js, Xcode та Android SDK є в [мобільному README](mobile/README.md).

```sh
npm --prefix mobile ci
npm --prefix mobile run check
npm --prefix mobile run ios
# або
npm --prefix mobile run android
```

## Характерник

«Характерник» підбирає конкретну відповідь із вбудованого каталогу, пам’ятає контекст короткого уточнення й відкриває потрібний розділ маршруту. Якщо даних бракує, він пропонує уточнити питання або дає контакт обласної лінії.

У збірках для App Store та Google Play помічник працює на пристрої. Dev-збірка підтримує текстовий чат, голосові повідомлення з редагованою розшифровкою й розмову з озвученням перевірених відповідей.

### Запуск онлайн у Dev

1. Встановіть залежності командами `npm ci` в корені й `npm --prefix mobile ci`.
2. Додайте у кореневий `.env` секрет `OPENAI_API_KEY` сервера. За потреби задайте `PORT` (типово 4173) і `OPENAI_MODEL` (типово `gpt-6-luna`).
3. Запустіть сервер командою `node --env-file=.env server.cjs`. Сервер слухає `127.0.0.1`.
4. Вкажіть у `mobile/.env.local` значення `EXPO_PUBLIC_ASSISTANT_URL=http://127.0.0.1:4173/api/assistant` для iPhone Simulator. Для Android з ADB можна під’єднати той самий порт командою `adb reverse tcp:4173 tcp:4173`. Для тестувальників використовуйте HTTPS-проксі з підтримкою WebSocket, обмеженням доступу та запитів. Задайте `APP_ORIGIN` як HTTPS-origin проксі й `ASSISTANT_DEV_TOKEN` як окремий випадковий код доступу в середовищі сервера. Передайте тестувальникам цей код для екрана «Помічник». Ключ OpenAI потрібен лише серверу.
5. Зберіть Dev-клієнт заново після встановлення нативних залежностей. Для наявного Android-проєкту застосуйте конфігурацію з [мобільного README](mobile/README.md#запуск). На екрані «Помічник» увімкніть «Онлайн-помічник». Текст доступний одразу, мікрофон запитує дозвіл під час першої голосової дії.

Сервер використовує `gpt-transcribe` для записів і `gpt-live-transcribe` для розмови. Модель підбирає ідентифікатори розділів. Текст і джерела надходять із тієї самої версії каталогу в застосунку. Озвучку відтворює український системний голос. За відсутності мережі доступний локальний гід. Питання, аудіо й розшифровки не записуються в журнали застосунку або сервера гіда. Верхня межа в Dev — 60 секунд на запис і 5 хвилин на голосову сесію.

Команда `npm run check` у корені перевіряє текст, запис і WebSocket на тестових відповідях провайдера. Реальні запити до OpenAI потребують ключа.

### Локальна модель для iPhone Simulator

Запустіть [llama.cpp](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md) із [Qwen3-1.7B GGUF](https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF). Для локальної перевірки ключ OpenAI не потрібен.

```sh
llama-server --model /path/to/Qwen3-1.7B-Q4_K_M.gguf --host 127.0.0.1 --port 4376 --ctx-size 6144 --parallel 1 --jinja --cors-origins localhost --no-webui
PORT=4175 ASSISTANT_LLAMA_URL=http://127.0.0.1:4376/v1/chat/completions node server.cjs
```

Під час запуску збірки для розробки на iPhone Simulator задайте `EXPO_PUBLIC_ASSISTANT_URL=http://127.0.0.1:4175/api/assistant` і ввімкніть «Онлайн-помічник» у застосунку. Локальну HTTP-адресу використовують для симулятора. На фізичному пристрої потрібна доступна HTTPS-адреса сервера.
