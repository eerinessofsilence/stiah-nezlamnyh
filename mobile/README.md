# Гід: Стяг незламних · мобільний застосунок

Незалежний гід для ветеранів, ветеранок, людей з інвалідністю внаслідок війни та їхніх родин із місцевими контактами Одещини. Мобільний застосунок використовує Expo SDK 58, React Native 0.88 та Expo Router. Комплект для випуску призначений для iPhone з iOS 16.4+ та Android з API 24+.

Інструкція зі збирання, підпису та заповнення карток доступна в [документації випуску](../docs/store-release.md).

У кожному з 14 маршрутів основні кроки та пояснення читаються прямо в застосунку, зокрема офлайн у збірці з вбудованим каталогом. Першоджерела й дати звірки доступні в розгортаному блоці «Джерела й перевірка» внизу. Подання заяви та рішення належать до повноважень відповідної установи.

## Запуск

Використовуйте Node.js 22.13+ у гілці 22. Інші підтримувані гілки вказано в полі `engines` у [package.json](package.json). Для iOS потрібні Xcode 26.4+, CocoaPods та сумісний симулятор або підключений iPhone. Для Android потрібні JDK 17, SDK Platform 37, Build Tools 37.0.0 та NDK 27.1.12297006. У конфігурації Gradle `compileSdk` дорівнює 37, а `targetSdk` — 36.

```sh
cd mobile
npm ci
npm run check
```

Виконайте `npm run ios` або `npm run android` для потрібної платформи з підключеним пристроєм або запущеним симулятором. Для конкретної моделі скористайтеся `npm run ios -- --device "iPhone 14 Pro"`, якщо відповідний пристрій створено в Xcode. Після змін у конфігурації Expo звірте їх із наявними нативними проєктами. Перед регенерацією збережіть ручні налаштування підпису й інтерфейсу.

Для першого запуску в авіарежимі потрібна збірка з вбудованим JS. На iPhone використовуйте TestFlight, а на симуляторі — `npx expo run:ios --configuration Release`. Для пристрою Android можна встановити підписаний тестовий APK. Збірка для розробки зазвичай завантажує код через Metro. [Інструкції з підпису та встановлення](../docs/store-release.md)

## Навігація та налаштування

- На екрані привітання натисніть «Продовжити», щоб перейти на головну. На головній можна натиснути плитку статусу, щоб зберегти свій вибір на пристрої й відкрити шторку з відповідними послугами.
- [Вкладки Expo Router](src/app/%28tabs%29/_layout.tsx) мають назви «Головна», «Послуги», «Помічник», «Контакти» та «Про гід». Основні іконки використовують Phosphor. «Помічник» має власні зображення для двох станів.
- На iOS 26+ вкладки використовують системний Liquid Glass. [GuideScreen](src/guide.tsx) додає зверху [матеріал UIKit із плавним переходом](modules/guide-edge-blur/ios/GuideEdgeBlurModule.swift), а знизу на iOS 26+ вмикає системний м’який ефект краю прокручування. На старіших iOS і Android працює панель із підписами, які масштабуються разом із системним шрифтом.
- На екрані «Про гід» є опис, правила користування і блок конфіденційності. Для посилань задайте `EXPO_PUBLIC_GUIDE_SITE_URL=https://nezlamnyi.eerinessbusiness.workers.dev` у `mobile/.env.local` або в середовищі, де збирається JS. Потрібна базова HTTPS-адреса. Застосунок додає `/privacy.html` і `/support.html`. Змінена адреса потрапляє до наступної збірки.
- У поточному коді «Про гід» має перемикач «Темна тема». [GuideThemeProvider](src/theme.tsx) починає зі світлої теми за відсутності збереженого вибору та зберігає зміну в SQLite. Застосована тема охоплює навігацію, системну панель стану й екрани гіда.
- Закладки та відмітки залишаються в картках маршрутів і зберігаються в SQLite через [GuideProvider](src/guide-state.tsx).

## Каталог

Після змін у `../catalog.js` виконайте `npm run sync:catalog`. `npm run check` перевіряє актуальність локального знімка, зв’язки між записами, типи TypeScript, пошук, підбір маршруту, контакти та формат збереженого прогресу.

## Перевірка на пристрої

| Сценарій | Очікуваний результат |
| --- | --- |
| Повністю закрити й відкрити застосунок у світлій і темній темах | На фоні теми по центру плавно з’являється повний логотип. Заставка плавно зникає, відкриваючи екран привітання або головну. З увімкненим зменшенням руху переходи миттєві. |
| Увімкнути авіарежим перед першим запуском і натиснути «Продовжити» | Екран привітання показує постер. Кнопка одразу відкриває головну. Каталог і «Характерник» доступні одразу. Зовнішнє посилання пропонує скопіювати адресу. Телефон і контакти видно офлайн. |
| Перезапустити застосунок після привітання, потім вибрати статус на головній | Після перезапуску одразу відкривається головна. Натискання статусу відкриває його послуги. Після закриття шторки можна вибрати будь-яку іншу добірку. |
| Головна → «Ветеран» → пошук «УБД» → картка → Назад | Перший результат — «Статус і документи». Після повернення до шторки запит збережено. Кнопка «Усі результати» відкриває повний список збігів на вкладці «Послуги». |
| Послуги → пошук «ВЛК», «МСЕК» або теми про родину | Відкривається відповідний маршрут із кроками та чек-листом. «Джерела й перевірка» розгортається внизу картки. |
| Послуги → «Реабілітація й протезування» → відмітити пункт і зберегти | Після повного перезапуску відкрийте ту саму картку: відмітка й стан закладки збережені. При видаленні закладки відмітка зберігається. |
| Помічник → «Протези і пільги» → вибрати тему → «Повний маршрут» | Доступні два варіанти. Після вибору «Протези» та питання «Як відремонтувати протез?» видно інструкцію з ремонту й відповідний розділ маршруту. Після повернення відкрито той самий діалог. Поле запитання доступне з відкритою клавіатурою. |
| Контакти → знайти «Ізма» → телефон, адреса, джерело | Видно місцевий контакт і кабінет. Телефон відкриває системний виклик. Тривале натискання номера або email дає можливість скопіювати значення. |
| Про гід → «Політика конфіденційності» та «Підтримка» | Публічні сторінки відкриваються без входу. Політика пояснює локальну обробку запитань, збереження прогресу та порядок видалення даних. На сторінці підтримки видно адресу для звернень. |
| Про гід → «Темна тема» → перезапустити застосунок | У збірці з перемикачем гід змінює оформлення, а вибір зберігається після перезапуску. |
| Нативні вкладки, великий текст, VoiceOver і TalkBack | Усі п’ять вкладок та їхній вибраний стан доступні. Чекбокс оголошує назву та стан. На вузькому екрані або з великим шрифтом плитки головної в одну колонку. Перевірте обидві теми, системну кнопку «Назад» Android і Reduce Transparency на iOS. |

«Характерник» у версіях із магазинів обробляє запитання на пристрої. Вони зберігаються в пам’яті лише протягом сеансу. Apple використовує [Privacy Manifest](ios/Styagnezlamnih/PrivacyInfo.xcprivacy) збірки й окрему декларацію App Privacy у картці магазину.
