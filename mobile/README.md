# Гід: Стяг незламних · мобільний застосунок

Незалежний гід для ветеранів, ветеранок, людей з інвалідністю внаслідок війни та їхніх родин із місцевими контактами Одещини. Мобільний застосунок використовує Expo SDK 58, React Native 0.88 та Expo Router. Комплект для випуску призначений для iPhone з iOS 16.4+ та Android з API 24+.

Інструкція зі збирання, підпису та заповнення карток доступна в [документації випуску](../docs/store-release.md).

У кожному з 14 маршрутів основні кроки та пояснення читаються прямо в застосунку, зокрема офлайн у збірці з вбудованим каталогом. Першоджерела доступні в розгортаному блоці «Джерела й перевірка», а дата редакції вказана під ним. Подання заяви та рішення належать до повноважень відповідної установи.

## Запуск

Використовуйте Node.js 22.13+ у гілці 22. Інші підтримувані гілки вказано в полі `engines` у [package.json](package.json). Для iOS потрібні Xcode 26.4+, CocoaPods та сумісний симулятор або підключений iPhone. Для Android потрібні JDK 17, SDK Platform 37, Build Tools 37.0.0 та NDK 27.1.12297006. У конфігурації Gradle `compileSdk` дорівнює 37, а `targetSdk` — 36.

```sh
cd mobile
npm ci
npm run check
```

Виконайте `npm run ios` або `npm run android` для потрібної платформи з підключеним пристроєм або запущеним симулятором. Для конкретної моделі скористайтеся `npm run ios -- --device "iPhone 14 Pro"`, якщо відповідний пристрій створено в Xcode. Після змін у конфігурації Expo звірте їх із наявними нативними проєктами. Перед регенерацією збережіть ручні налаштування підпису й інтерфейсу.

Для першого запуску в авіарежимі потрібна збірка з вбудованим JS. На iPhone використовуйте TestFlight, а на симуляторі — `npx expo run:ios --configuration Release`. Для пристрою Android можна встановити підписаний тестовий APK. Збірка для розробки зазвичай завантажує код через Metro. [Інструкції з підпису та встановлення](../docs/store-release.md)

## Навігація та налаштування

- Після запуску гід відкриває головну. Натисніть плитку статусу, щоб зберегти свій вибір на пристрої й відкрити шторку з відповідними послугами.
- [Вкладки Expo Router](src/app/%28tabs%29/_layout.tsx) мають назви «Головна», «Послуги», «Помічник», «Новини» та «Меню». Основні іконки використовують Phosphor. «Помічник» має власні зображення для двох станів.
- «Новини» завантажують до 10 останніх публікацій зі [стрічки Мінветеранів](https://mva.gov.ua/category/86-novini), коли відкрито вкладку. Заголовки, дати й посилання останньої успішно завантаженої стрічки зберігаються на пристрої. Статті відкриваються на сайті Мінветеранів.
- На iOS 26+ вкладки використовують системний Liquid Glass. [GuideScreen](src/guide.tsx) додає зверху [матеріал UIKit із плавним переходом](modules/guide-edge-blur/ios/GuideEdgeBlurModule.swift), а знизу на iOS 26+ вмикає системний м’який ефект краю прокручування. На старіших iOS і Android працює панель із підписами, які масштабуються разом із системним шрифтом.
- У «Меню» рядок «Контакти» відкриває екран `/contacts` із гарячою лінією й пошуком контактів, а «Про гід» — екран `/about` з описом і блоком конфіденційності. Кнопка «Назад» повертає до меню. Для посилань підтримки й конфіденційності задайте `EXPO_PUBLIC_GUIDE_SITE_URL=https://nezlamnyi.eerinessbusiness.workers.dev` у `mobile/.env.local` або в середовищі, де збирається JS. Потрібна базова HTTPS-адреса. Застосунок додає `/privacy.html` і `/support.html`. Змінена адреса потрапляє до наступної збірки.
- У «Меню» є перемикач «Темна тема». [GuideThemeProvider](src/theme.tsx) початково використовує тему пристрою. Після перемикання явний вибір темної або світлої теми зберігається в SQLite й застосовується до навігації, системної панелі стану та екранів гіда.
- Відмітки в чек-листах автоматично зберігаються в SQLite через [GuideProvider](src/guide-state.tsx).

## Каталог

Після змін у `../catalog.js` виконайте `npm run sync:catalog`. `npm run check` перевіряє актуальність локального знімка, зв’язки між записами, типи TypeScript, пошук, підбір маршруту, контакти та формат збереженого прогресу.

## Перевірка на пристрої

| Сценарій | Очікуваний результат |
| --- | --- |
| Повністю закрити й відкрити застосунок у світлій і темній темах | Логотип з’являється за 0,75 с, залишається видимим 2 с і зникає за 0,25 с. Після цих 3 с заставка закривається, щойно перший екран готовий. З увімкненим зменшенням руху перший екран відкривається одразу після готовності. |
| Увімкнути авіарежим перед першим запуском | Після заставки одразу відкривається головна. Каталог і «Характерник» доступні одразу. Зовнішнє посилання пропонує скопіювати адресу. Телефон і контакти видно офлайн. |
| Перезапустити застосунок, потім вибрати статус на головній | Після перезапуску одразу відкривається головна. Натискання статусу відкриває його послуги. Після закриття шторки можна вибрати будь-яку іншу добірку. |
| Головна → «Ветеран» → пошук «УБД» → картка → Назад | Перший результат — «Статус і документи». Кнопка повернення в картці відкриває шторку того самого статусу з початковим списком. |
| Послуги → пошук «ВЛК», «МСЕК» або теми про родину | Відкривається відповідний маршрут із кроками та чек-листом. «Джерела й перевірка» розгортається внизу картки. |
| Послуги → «Реабілітація й протезування» → відмітити пункт | Після повного перезапуску відкрийте ту саму картку й перевірте відмітку. Зніміть її та перевірте, що зміна також збереглася. |
| Помічник → «Протези і пільги» → вибрати тему → «Повний маршрут» | Доступні два варіанти. Після вибору «Протези» та питання «Як відремонтувати протез?» видно інструкцію з ремонту й відповідний розділ маршруту. Після повернення відкрито той самий діалог. Поле запитання доступне з відкритою клавіатурою. |
| Меню → «Контакти» → знайти «Ізма» → телефон, адреса, джерело | Видно місцевий контакт і кабінет. Телефон відкриває системний виклик. Окремі кнопки копіюють номер і email. У списку посилань читача екрана джерела розрізняються за назвою організації. |
| Меню → «Про гід» → «Політика конфіденційності» та «Підтримка» | Публічні сторінки відкриваються без входу. Політика пояснює локальну обробку запитань, збереження прогресу та порядок видалення даних. На сторінці підтримки видно адресу для звернень. |
| Меню → «Темна тема» → змінити тему пристрою й перезапустити гід | До першого перемикання гід слідує темі пристрою. Після перемикання світла або темна палітра зберігається й діє після перезапуску за будь-якої теми пристрою. |
| Новини → відкрити публікацію, потім повернутися у вкладку в авіарежимі | «Новини» розташовані ліворуч від «Меню». З інтернетом видно останні публікації Мінветеранів, а посилання відкриває оригінал. В офлайні видно заголовки й дати останньої успішно завантаженої стрічки. |
| Найбільший системний текст → «Послуги», маршрут, шторка послуг і «Помічник» | У порожніх полях пошуку й запитання видно підказки. Введіть текст підказки, щоб звірити центрування. Рядок зберігає висоту й положення в полі. Кнопки повернення й закриття стоять над заголовком. У шторці можна прокрутити заголовок, щоб дістатися поля пошуку. |
| Нативні вкладки, великий текст, VoiceOver і TalkBack | Усі п’ять вкладок та їхній вибраний стан доступні. Чекбокс оголошує назву та стан. На вузькому екрані або з великим шрифтом плитки головної в одну колонку. Перевірте обидві теми, системну кнопку «Назад» Android і Reduce Transparency на iOS. |

«Характерник» у версіях із магазинів обробляє запитання на пристрої. Вони зберігаються в пам’яті лише протягом сеансу. Apple використовує [Privacy Manifest](ios/Styagnezlamnih/PrivacyInfo.xcprivacy) збірки й окрему декларацію App Privacy у картці магазину.
