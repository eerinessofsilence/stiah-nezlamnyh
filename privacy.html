Для застосунку «Гід: Стяг незламних» на iOS та Android. За політику відповідає команда гіда. Оновлено 26 листопада 2026 року.

Підтримка English summary

Дані в застосунку

Застосунок працює без облікового запису. Пошук у каталозі виконується на пристрої. У версіях з App Store і Google Play «Характерник» також використовує вбудований каталог, коли онлайн-допомогу вимкнено, немає мережі або сервер недоступний. У застосунку немає реклами й аналітичних трекерів.

Після вашої явної згоди «Характерник» надсилає текст відправленого повідомлення, ідентифікатор теми попередньої відповіді та версію каталогу на сервер гіда в Cloudflare. Сервер передає текст, ідентифікатор теми й потрібні матеріали каталогу до OpenAI, щоб підібрати відповідь із гіда або сформулювати відповідь на загальне запитання. Профіль, чернетки й повна історія чату не входять до текстового запиту. Будь ласка, не називайте в повідомленнях імена, номери документів чи інші відомості, за якими вас можна впізнати.

На iPhone голосова допомога потребує окремої згоди. Запис і жива розмова також потребують дозволу на мікрофон. Для розпізнавання Cloudflare передає закінчений запис або потік аудіо до OpenAI. Запис повідомлення тимчасово зберігається в кеші пристрою й видаляється після розпізнавання або скасування. Розшифровка повідомлення відкривається як чернетка. У живій розмові розпізнане запитання й тему попередньої відповіді передаємо до OpenAI для пошуку в гіді або формування відповіді на загальне запитання.

Після згоди на голосову допомогу Cloudflare передає до ElevenLabs готовий текст, який треба озвучити голосом «Леонід Драпей». Це відбувається, коли ви прослуховуєте відповідь у чаті або отримуєте відповідь у живій розмові. Запит на озвучення містить текст відповіді. Запис із мікрофона, оригінальне запитання та історія чату до цього запиту не входять. Отримане звучання тимчасово зберігається в кеші пристрою для відтворення. Коли онлайн-озвучення недоступне, застосунок може використати український системний голос. Політика конфіденційності ElevenLabs.

Cloudflare обробляє IP-адресу для доставки запитів і обмеження їхньої частоти. Сервер гіда не зберігає запитання, відповіді чи аудіо та зберігає загальні лічильники використання. Згоди зберігаються на пристрої. Їх можна відкликати в «Меню» → «Про гід», вимкнувши «Онлайн-допомога» або «Голосова допомога».

Ми вимикаємо збереження відповідей у запитах до OpenAI. За стандартними правилами OpenAI не зберігає записані повідомлення для контролю зловживань. Дані текстових запитів і живої розмови OpenAI може зберігати для цього до 30 днів, а в окремих випадках довше, якщо цього вимагає закон. OpenAI за замовчуванням не використовує дані API для тренування моделей. Правила обробки даних API OpenAI.

У Dev-збірці з налаштованим сервером «Характерник» автоматично надсилає відправлене запитання й тему розмови на сервер гіда для підбору розділу або формування відповіді на загальне запитання. Якщо сервер використовує OpenAI, ці дані також надходять до OpenAI. Під час голосової дії аудіо надходить на сервер гіда та в OpenAI для розпізнавання. Якщо ввімкнено серверне озвучення, готовий текст відповіді надходить на сервер гіда. Piper синтезує мовлення локально. Для голосу «Леонід Драпей» сервер передає лише текст відповіді до ElevenLabs для синтезу мовлення. Політика конфіденційності ElevenLabs. Застосунок використовує тимчасовий файл у кеші пристрою для відтворення. Для тестів використовуйте запитання без персональних даних.

  • Вибраний статус зберігається в застосунку на пристрої. Щоб змінити його, натисніть іншу плитку статусу на головній. Якщо ви вказали ім’я в попередній версії, воно також залишається в локальному сховищі. Повне видалення застосунку прибирає ці дані.
  • Вибір теми зберігається на пристрої й відновлюється після перезапуску. Відмітки та закладки зі старіших версій можуть залишатися в локальному сховищі. Повне видалення застосунку прибирає ці дані з його локального сховища. Системними резервними копіями керують iOS або Android.
  • Чати «Характерника» разом із назвами, чернетками й закріпленнями залишаються в пам’яті поточного сеансу та зникають після повного перезапуску застосунку. Окремий чат можна видалити в історії чатів.

Новини, посилання й дзвінки

Коли відкрито вкладку «Новини» й доступний інтернет, гід завантажує стрічки з mva.gov.ua та veteran.com.ua, щоб показати заголовки, дати й зображення. Ці сайти можуть отримати технічні дані запитів, зокрема IP-адресу. Гід не надсилає їм ваш статус, пошукові запити або запитання. Заголовки, дати й посилання останньої завантаженої стрічки з кожного сайту зберігаються на пристрої для перегляду офлайн.

Коли ви відкриваєте посилання, номер телефону або адресу електронної пошти, гід передає вибрану дію системному застосунку. Подальшу обробку визначає відповідний сайт, поштовий сервіс або оператор зв’язку.

Публічні сторінки підтримки й приватності розміщено на Cloudflare. Для доставки й захисту цих сторінок Cloudflare може обробляти технічні дані запитів, зокрема IP-адресу. На сторінках немає форм збору даних або коду аналітики. Політика Cloudflare.

Звернення до підтримки та видалення даних

Якщо ви самі пишете до служби підтримки, команда отримує вашу адресу електронної пошти, текст листа та все, що ви додали до нього. Поштова скринька працює через Gmail. Команда використовує листування для відповіді й опрацювання звернення та зберігає його, поки воно потрібне для цього.

З питаннями про приватність або із запитом на видалення листування напишіть на stiah.guide@gmail.com. Будь ласка, не надсилайте документи, їхні номери чи медичні дані.

Privacy policy summary

For the iOS and Android app «Гід: Стяг незламних». No account is required. Catalog search runs on-device. In store builds, the assistant uses the bundled guide when offline, when online assistance is switched off or when the server is unavailable. The app includes no advertising or analytics trackers.

After you explicitly allow online assistance, the app sends the submitted message, the previous reply’s topic ID and the catalog version to the guide server on Cloudflare. The server sends the message, topic ID and relevant catalog materials to OpenAI to select an answer. The text request excludes your profile, drafts and entire chat history. Please keep names, document numbers and other identifying details out of your messages.

Voice assistance on iPhone requires separate consent. Recording and live conversation also require microphone permission. Cloudflare forwards completed recordings or live audio to OpenAI for transcription. A recorded message is kept temporarily in the device cache and deleted after transcription or cancellation. Its transcript opens as a draft. In a live conversation, the transcribed question and previous topic are sent to OpenAI to look up or generate an answer.

With voice assistance enabled, Cloudflare sends the prepared answer to ElevenLabs for synthesis with the Leonid Drapei voice when you play a reply in chat or receive a reply in a live conversation. The synthesis request contains the answer text and excludes microphone audio, the original question and chat history. The device temporarily caches the generated audio for playback. When online synthesis is unavailable, the app can use a Ukrainian system voice. ElevenLabs privacy policy.

Cloudflare processes IP addresses to deliver and rate-limit requests. The guide server stores aggregate usage counters and does not store questions, answers or audio. Consent stays on-device. You can withdraw it in Menu → About the guide by switching off Online assistance or Voice assistance. We disable API response storage. Under its default API rules, OpenAI does not retain completed recordings for abuse monitoring. It may retain text requests and live conversation data for up to 30 days for abuse monitoring, or longer if legally required. OpenAI does not use API data for training by default. OpenAI API data controls.

In development builds with a server configured, the assistant automatically sends submitted questions and the current topic to the guide server. If the server uses OpenAI, it forwards these data to OpenAI. During voice use, the guide server forwards audio to OpenAI for transcription. For speech synthesis, the server either sends the prepared answer to ElevenLabs for the Leonid voice or generates the Mykyta voice locally with Piper. Playback uses a temporary file in the device cache. Use questions without personal data for testing.

Your selected status and theme preference stay in local app storage. To change your status, tap a different status tile on the home screen. Checklist marks, route bookmarks and an optional name from older versions may remain on the device. Deleting the app removes its local data. The operating system controls backups. Assistant chats, titles, drafts and pins stay in session memory and clear after a full app restart. You can remove individual chats from chat history.

The News tab retrieves public news and images from mva.gov.ua when open and online. The site can receive technical request data such as your IP address. Your status, searches and questions are excluded from these requests. The app keeps the latest feed metadata locally for offline viewing.

External websites, calls and email use the device’s system apps. Cloudflare may process technical request data when you open these public pages. If you email support, the project uses your address and message to respond and keeps the correspondence as long as needed to handle the request. For privacy questions or to request deletion of support correspondence, email stiah.guide@gmail.com.
