Політика конфіденційності

Для застосунку «Гід: Стяг незламних» на iOS та Android. За політику відповідає команда гіда. Оновлено 25 листопада 2026 року.

Підтримка English summary

Дані в застосунку

Застосунок працює без облікового запису. Пошук у каталозі виконується на пристрої. У версіях з App Store і Google Play «Характерник» також використовує вбудований каталог, коли онлайн-допомогу вимкнено, немає мережі або сервер недоступний. У застосунку немає реклами й аналітичних трекерів.

Після вашої явної згоди «Характерник» надсилає текст відправленого повідомлення, ідентифікатор теми попередньої відповіді та версію каталогу на сервер гіда в Cloudflare. Сервер передає текст, ідентифікатор теми й потрібні матеріали каталогу до OpenAI для пошуку відповіді. Профіль, чернетки, повна історія чату й аудіо з магазинної версії в цей запит не входять. Будь ласка, не додавайте до повідомлень імена, номери документів чи інші відомості, за якими вас можна впізнати.

Cloudflare обробляє IP-адресу для доставки запиту й обмеження частоти. Сервер гіда не записує запитання або відповіді й зберігає лише загальний лічильник використання онлайн-допомоги. Згода зберігається на пристрої. Її можна відкликати в «Меню» → «Про гід» → «Онлайн-допомога», після чого наступні запитання оброблятимуться на пристрої.

Ми вимикаємо збереження відповідей у запитах до OpenAI. За стандартними налаштуваннями OpenAI може зберігати дані запиту до 30 днів для контролю зловживань, а в окремих випадках довше, якщо цього вимагає закон. OpenAI за замовчуванням не використовує дані API для тренування моделей. Правила обробки даних API OpenAI.

У тестовій збірці з налаштованим сервером «Характерник» автоматично надсилає відправлене запитання й тему розмови на сервер гіда для підбору розділу. Якщо сервер використовує OpenAI, ці дані також надходять до OpenAI. Під час голосової дії аудіо надходить на сервер гіда та в OpenAI для розпізнавання. Якщо ввімкнено голос «Микита», готовий текст відповіді надходить на сервер гіда для локального синтезу мовлення. Застосунок використовує тимчасовий файл у кеші пристрою для відтворення. Для тестів використовуйте запитання без персональних даних.

  • Вибраний статус зберігається в застосунку на пристрої. Щоб змінити його, натисніть іншу плитку статусу на головній. Якщо ви вказали ім’я в попередній версії, воно також залишається в локальному сховищі. Повне видалення застосунку прибирає ці дані.
  • Вибір теми зберігається на пристрої й відновлюється після перезапуску. Відмітки та закладки зі старіших версій можуть залишатися в локальному сховищі. Повне видалення застосунку прибирає ці дані з його локального сховища. Системними резервними копіями керують iOS або Android.
  • Чати «Характерника» разом із назвами, чернетками й закріпленнями залишаються в пам’яті поточного сеансу та зникають після повного перезапуску застосунку. Окремий чат можна видалити в історії чатів.

Новини, посилання й дзвінки

Коли відкрито вкладку «Новини» й доступний інтернет, гід завантажує стрічки з mva.gov.ua та veteran.com.ua, щоб показати заголовки, дати й зображення. Ці сайти можуть отримати технічні дані запитів, зокрема IP-адресу. Гід не надсилає їм ваш статус, пошукові запити або запитання. Заголовки, дати й посилання останньої завантаженої стрічки з кожного сайту зберігаються на пристрої для перегляду офлайн.

Коли ви відкриваєте посилання, номер телефону або адресу електронної пошти, гід передає вибрану дію системному застосунку. Подальшу обробку визначає відповідний сайт, поштовий сервіс або оператор зв’язку.

Публічні сторінки підтримки й приватності розміщено на Cloudflare. Для доставки й захисту цих сторінок Cloudflare може обробляти технічні дані запитів, зокрема IP-адресу. На сторінках немає форм збору даних або коду аналітики. Політика Cloudflare.

Звернення до підтримки та видалення даних

Якщо ви самі пишете до служби підтримки, команда отримує вашу адресу електронної пошти, текст листа та все, що ви додали до нього. Поштова скринька працює через Gmail. Команда використовує листування для відповіді й опрацювання звернення та зберігає його, поки воно потрібне для цього.

З питаннями про приватність або із запитом на видалення листування напишіть на stiah.guide@gmail.com. Будь ласка, не надсилайте документи, їхні номери чи медичні дані.

Privacy policy summary

For the iOS and Android app «Гід: Стяг незламних». No account is required. Catalog search runs on-device. In store builds, the assistant uses the bundled guide when offline, when online assistance is switched off or when the server is unavailable. The app includes no advertising or analytics trackers.

After you explicitly allow online assistance, the app sends the submitted message, the ID of the previous reply’s topic and the catalog version to the guide’s server hosted on Cloudflare. The server sends the message, topic ID and relevant catalog materials to OpenAI to select an answer. The request excludes your profile, drafts, entire chat history and store-build audio. Please keep names, document numbers and other identifying details out of messages.

Cloudflare processes the IP address to deliver and rate-limit the request. The guide server does not log questions or answers and stores only an aggregate usage counter. The app stores your consent on-device. To withdraw it for future questions, open Menu → About the guide → Online assistance. We disable API response storage. Under its default settings, OpenAI may retain request data for abuse monitoring for up to 30 days, or longer if legally required, and does not use API data for training by default. OpenAI API data controls.

In test builds with a server configured, the assistant automatically sends submitted questions and the current topic to the guide server. If the server uses OpenAI, it forwards these data to OpenAI. During voice use, the guide server forwards audio to OpenAI for transcription. If the Mykyta voice is enabled, the app sends the prepared answer to the guide server for local speech synthesis and uses a temporary file in the device cache for playback. Use questions without personal data for testing.

Your selected status and theme preference stay in local app storage. To change your status, tap a different status tile on the home screen. Checklist marks, route bookmarks and an optional name from older versions may remain on the device. Deleting the app removes its local data. The operating system controls backups. Assistant chats, titles, drafts and pins stay in session memory and clear after a full app restart. You can remove individual chats from chat history.

The News tab retrieves public news and images from mva.gov.ua when open and online. The site can receive technical request data such as your IP address. Your status, searches and questions are excluded from these requests. The app keeps the latest feed metadata locally for offline viewing.

External websites, calls and email use the device’s system apps. Cloudflare may process technical request data when you open these public pages. If you email support, the project uses your address and message to respond and keeps the correspondence as long as needed to handle the request. For privacy questions or to request deletion of support correspondence, email stiah.guide@gmail.com.
